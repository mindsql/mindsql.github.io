# mindsql.github.io

个人网站源码，由 [GitHub Pages](https://pages.github.com) 驱动，访问地址：

**https://mindsql.github.io**

## 结构

- `index.html` — 单页站点，纯 HTML + 内联 CSS，零依赖（无框架、无 CDN），改完推送即生效

## 如何更新

```bash
# 改 index.html 后：
git add .
git commit -m "update site"
git push
```

推送后约 1 分钟生效。
